# 프리뷰 중앙 정렬 스냅 설계

날짜: 2026-07-06
상태: 승인됨

## 개요

리사이즈(프리셋)·레이아웃 에디터의 모니터 프리뷰에서 영역을 드래그해 옮길 때,
영역의 **중심**이 화면 가로/세로 중앙에 가까워지면 착 정렬되게 한다.

## 배경

현재 두 캔버스(`MonitorCanvas`, `LayoutMonitorCanvas`)는 엣지 좌표를
분수(0, 1/4, 1/3, 1/2, 2/3, 3/4, 1) 위치에만 스냅한다. 임의 크기 영역을
정중앙에 놓으면 좌표가 어중간한 분수가 되어 스냅이 걸리지 않는다.

## 설계

- 두 캔버스의 **이동(body drag) 제스처**에 중앙 스냅 추가:
  `snapMovePosition(_:size:center:total:)` — 상자 중심이 usable 영역
  (deadzone 반영) 중앙에서 `0.03 * total` 이내면 중앙 정렬 좌표를 반환,
  아니면 기존 `snapValue`(엣지 분수 스냅)로 폴백. 가로/세로 독립 적용.
- 중앙 기준은 `usableBounds.midX/midY` — 실제 배치 영역과 일치.
- **스냅 기준선 강조(후속 요청)**: 이동 드래그에서 스냅이 걸리면 어느 선에
  붙었는지 보이도록, `snapMovePosition`이 스냅된 기준선의 모니터 px 좌표를
  함께 반환하고 캔버스가 이를 canvas 좌표로 변환해 `SnapGrid`에 전달한다.
  `SnapGrid`는 해당 세로/가로 선을 기존 점선 위에 **주황색 실선(1.5pt)**으로
  덧그린다. 마우스를 떼면(onEnded) 강조 상태를 지우고 그리드도 사라진다.

## 범위 제외

- 코너 리사이즈·신규 영역 생성 제스처 (이동에만 적용)
- 다른 영역(placement) 간의 상호 정렬 가이드

## 테스트

private 뷰 헬퍼라 단위 테스트 없음. 수동 확인: 프리셋/레이아웃 프리뷰에서
영역을 중앙 근처로 드래그 → 가로/세로 중앙에 착 붙음, 벗어나면 기존 분수
스냅 동작 유지.
