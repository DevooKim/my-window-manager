# Hyperkey 별 표시 설계

## 목표

단축키의 보조키가 정확히 Control, Option, Shift, Command 네 개로 구성된 Hyperkey 조합이면 기존 네 기호 대신 `✦` 하나로 표시한다.

예: `⌃⌥⇧⌘K` → `✦K`

## 구현

- `HotkeyConfig.displayString`이 네 보조키의 Carbon 플래그와 정확히 일치하는지 판별한다.
- 정확히 일치하면 보조키 부분을 `✦`로 만들고 기존 키 설명을 이어 붙인다.
- 그 외 조합은 현재 순서와 기호(`⌃`, `⌥`, `⇧`, `⌘`)를 그대로 유지한다.
- 표시 로직만 변경하며 단축키 등록, 캡처, 저장 형식은 변경하지 않는다.

## 검증

- Hyperkey와 문자 키 조합이 `✦`와 문자 키로 표시되는지 모델 테스트로 확인한다.
- 일반 보조키 조합의 기존 표시가 유지되는지 회귀 테스트로 확인한다.
